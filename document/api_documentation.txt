1.Introduction to Remind Interface The Remind middleware is divided into a data communication module and a data operation module, corresponding to the RemindCommunicationStack and RemindData libraries, respectively. Currently, we have only opened up the RemindCommunicationStack library. Below, we provide a brief introduction to this communication library.
The RemindCommunicationStack is a communication module that primarily offers a unified interface for data transmission during surgery. The application layer only needs to perform some simple configurations to use it directly, without considering the communication method, how to establish connections between nodes, data storage for communication, or communication efficiency issues, thus improving development efficiency.

2.Interface Introduction of RemindCommunicationStack Module

bool LoadConfig(const std::string &device_path, const std::string &topology_path);
    Function: Load node parameters and topology configuration files
    Parameters:
        device_path: The path to the node configuration file, which is placed in the config folder in the same directory as the executable file by default
        topology_path: The path to the node topology configuration file, which is placed in the config folder in the same directory as the executable file by default
    Return value: Returns true if loaded successfully, false if failed; if failed, the reason can be viewed through the callback function RegisterMessageFunc

void SetPatientSession(const std::string &patient_id, const std::string &session_id);
    Function: Set the patient and medical record ID, which is obtained when creating patient and medical record information
    Parameters:
        patient_id: Patient ID, the ID generated when creating patient information
        session_id: Patient medical record ID, the ID generated when creating a patient's surgery information

bool Init(uint64_t bid = 0);
    Function: Perform node initialization
    Parameters:
        bid: The current node ID, combined with the loaded topology configuration file, to find other nodes connected to this node. If not filled in, it defaults to the node selected in the configuration file
    Return value: Returns true if executed successfully, false if failed; if failed, the reason can be viewed through the callback function RegisterMessageFunc

bool Launch();
    Function: Start the communication module
    Parameters: None
    Return value: Returns true if executed successfully, false if failed; if failed, the reason can be viewed through the callback function RegisterMessageFunc

bool Terminate();
    Function: Stop the communication module

RemindMessageQueue *GetOutputQueue(uint64_t bid = 0);
    Function: Get the corresponding output queue pointer by ID, for example, if the destination node ID to send to is 123, then input 123 to get the queue for that node, and then send data through the queue
    Parameters:
        bid: The ID of the destination node
    Return value: Returns a pointer to the queue if successful, a null pointer if failed; if failed, the reason can be viewed through the callback function RegisterMessageFunc

RemindMessageQueue *GetInputQueue(uint64_t bid = 0);
    Function: Get the corresponding input queue pointer by ID, for example, if the node ID to receive information is 123, then input 123 to get the queue for that node, and then receive data through the queue
    Parameters:
        bid: The ID of the receiving node
    Return value: Returns a pointer to the queue if successful, a null pointer if failed; if failed, the reason can be viewed through the callback function RegisterMessageFunc

RemindMessageQueue *DefineInputQueue(const std::string &queue_name,
                                       const std::string &exchange,
                                       const std::string &rout_key,
                                       bool no_msg_header = false);
    Function: Define a custom receiving queue and return a pointer to the queue, corresponding to the sending queue
    Parameters:
        queue_name: Custom queue name
        exchange: Custom channel name
        rout_key: Custom routing key
        no_msg_header: Whether the message includes a message header when sent, if true, the data is sent as raw data, and the data is not saved to the database
    Return value: Returns a pointer to the queue if successful, a null pointer if failed; if failed, the reason can be viewed through the callback function RegisterMessageFunc

RemindMessageQueue *DefineOutputQueue(const std::string &queue_name,
                                         const std::string &exchange,
                                         const std::string &rout_key,
                                         bool no_msg_header = false);
    Function: Define a custom sending queue and return a pointer to the queue, corresponding to the receiving queue
    Parameters:
        queue_name: Custom queue name
        exchange: Custom channel name
        rout_key: Custom routing key
        no_msg_header: Whether the message includes a message header when sent, if true, the received data is raw data, and the data is not saved to the database
    Return value: Returns a pointer to the queue if successful, a null pointer if failed; if failed, the reason can be viewed through the callback function RegisterMessageFunc

bool GetDeviceStatus(std::map<uint64_t, std::string> &status);
    Function: Get the status of all nodes
    Parameters:
        status: A map variable that stores the status information returned, such as "a" for online, "i" for offline
    Return value: Returns true if successful, false if failed

bool GetDeviceStatus(uint64_t bid, std::string &status);
    Function: Get the status of a node by node ID
    Parameters:
        status: The returned status information, such as "a" for online, "i" for offline
    Return value: Returns true if successful, false if failed

void SetCurrentDeviceStatus(const std::string &status);
    Function: Set the current node status
    Parameters:
        status: The status that can be set can be referenced in the CommonNodeStatus in DiagnosisInfo.h

void RegisterMessageFunc(const std::function<void(std::string &)> msg_callback);
    Function: Message callback function, returns exception or debug information
    Parameters:
        msg_callback: Callback function

QString GetCurrentNodeName();
    Function: Get the current node name

QString GetCurrentNodeId();
    Function: Get the current node ID

QMap<QString, QString> GetNodeConnectList();
    Function: Get all the destination nodes connected to the current node

shared_ptr<InfoDeviceNodes> GetNodeConfig();
    Function: Get node configuration information
